# Casino Pro Demo

Android için WebView tabanlı, çevrimdışı oynanabilen sanal jeton slot demosu.

## Özellikler
- 5x3 makaralı slot oyunu
- 3 tema seçimi
- Sanal bakiye ve bahis ayarı
- Rastgele sembol üretimi ve demo kazanç hesabı
- İnternet, hesap veya ödeme gerektirmez

## APK oluşturma
GitHub Actions içinden **Build Casino Pro Demo APK** iş akışını çalıştırın. Başarılı çalışmanın Artifacts bölümünden `Casino-Pro-Demo-APK` dosyasını indirin.
